# References

Drop inspiration here: other studios' invitations, saved pages, videos, screenshots, mood boards.

- **Everything in this folder stays on your machine.** Git ignores it (only this README is
  committed), and the build, lint and deploy never read it.
- **Look, never copy.** Nothing from here goes into the product: no images, video, artwork, code or
  text. We study what works and then make our own original version.
- Sacred art (deities, scripture) from references is never traced or regenerated; it comes only from
  licensed, vetted sources.
